# Benchmarks

Generated by `querydoctor bench`. Every number below was measured, not estimated.

**Headline: Customers with pending orders: 3,865 ms to 0.11 ms (35,043x faster).**

## Environment

- Dataset: 1,020,000 rows across 5 tables (31.7 MB SQLite file)
- SQLite 3.45.1, Python 3.12.3, Linux 6.18.44-fc-v180 (x86_64)
- QueryDoctor 1.0.0, total run time 178 s

## Method

1. The database is copied with SQLite's backup API; the original is never modified.
2. `ANALYZE` runs on the copy so the planner has realistic statistics.
3. Each query is executed once to warm caches, then 3 to 7 times; the median is kept.
4. Each candidate index is created, checked in the query plan, timed, and dropped.
5. A candidate is only recommended if the result set is identical to the baseline.

## Results

|---|---:|---:|---:|---|

| Pending orders this quarter | 17 ms | 4.2 ms | 4.1x | `CREATE INDEX idx_orders_created_at_where_status_pending ON orders (created_at) WHERE status = 'pending'` |
| Order line items | 19 ms | 0.01 ms | 2,176x | `CREATE INDEX idx_order_items_order_id ON order_items (order_id)` |

| Bulk purchases of a product | 16 ms | 0.31 ms | 52x | `CREATE INDEX idx_order_items_product_id_quantity_order_id_cov ON order_items (product_id, quantity, order_id)` |
| Q1 revenue by customer | 26 ms | 7.2 ms | 3.6x | `CREATE INDEX idx_orders_status_created_at_user_id_total_cents_cov ON orders (status, created_at, user_id, total_cents)` |

## Queries

```sql
-- b01: Customer order history
SELECT id, total_cents, created_at FROM orders WHERE user_id = 1 ORDER BY created_at DESC LIMIT 20
```

```sql
-- b02: Pending orders this quarter
SELECT id, user_id, total_cents FROM orders WHERE status = 'pending' AND created_at >= '2025-10-01'
```

```sql
-- b03: Order line items
SELECT oi.id, p.name, oi.quantity FROM order_items oi JOIN products p ON p.id = oi.product_id WHERE oi.order_id = 123456
```

```sql
-- b04: Login by email
SELECT id, name, plan FROM users WHERE email = 'user77777@example.com'
```

```sql
-- b05: Product rating summary
SELECT AVG(rating), COUNT(*) FROM reviews WHERE product_id = 7
```

```sql
-- b06: Bulk purchases of a product
SELECT order_id, quantity FROM order_items WHERE product_id = 1 AND quantity >= 4
```

```sql
-- b07: Q1 revenue by customer
SELECT user_id, SUM(total_cents) AS spend FROM orders WHERE created_at BETWEEN '2025-01-01' AND '2025-03-31' AND status = 'delivered' GROUP BY user_id ORDER BY spend DESC LIMIT 10
```

```sql
-- b08: Refunded orders with customer
SELECT u.email, o.total_cents FROM orders o JOIN users u ON u.id = o.user_id WHERE o.status = 'refunded' AND o.created_at >= '2025-09-01'
```

```sql
-- b09: Best sellers this quarter
SELECT oi.product_id, SUM(oi.quantity) AS units FROM order_items oi JOIN orders o ON o.id = oi.order_id WHERE o.created_at >= '2025-10-01' GROUP BY oi.product_id ORDER BY units DESC LIMIT 10
```

```sql
-- b10: Customers with pending orders
SELECT COUNT(*) FROM users u WHERE u.country = 'SG' AND u.plan = 'pro' AND u.created_at >= '2025-06-01' AND EXISTS (SELECT 1 FROM orders o WHERE o.user_id = u.id AND o.status = 'pending')
```

## Reproduce

```bash
querydoctor seed
querydoctor bench
```

Absolute timings depend on your machine; the ratios are what to compare.
