# ADR 0006: Dashboard in plain JavaScript and CSS, no HTML files, no build step

- Status: accepted
- Date: 2026-10

## Context

The dashboard should be easy to read, run and review. A bundler and a framework would add a
Node toolchain to a Python project, and static HTML would put markup in a third language.

## Decision

The interface is native ES modules (`src/querydoctor/web/static/*.js`) plus one stylesheet.
All DOM is built with a small `h()` helper that inserts text as text nodes, so query text can
never be interpreted as markup. The only markup is the boot document, generated by
`web/__init__.py`. Charts are SVG built in JavaScript. A test fails if any `.html` file is added
to the repository, with one exception: the root `index.html`, a ten-line host page for the GitHub
Pages demo. GitHub Pages cannot run Python, so that page sets `QUERYDOCTOR_STATIC` and the same
modules replay `docs/benchmarks.json` through a small adapter in `api.js` instead of calling the
REST API.

## Consequences

- `pip install` is all anyone needs; nothing to compile.
- No framework conveniences: views re-render by rebuilding their DOM.
- Browsers must support ES modules (every current browser does).
- CI syntax-checks every module with `node --check`.
